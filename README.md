# Employee Attrition Prediction

## Data Zest — Data Science Capstone Project | Cohort 7

### Turning Data into Insights, and Insights into Impact

## Project Overview

Employee turnover is a major challenge for organisations because the loss of employees can increase recruitment costs, reduce productivity and affect team performance.

This project develops a machine learning classification system to identify employees who may be at risk of leaving an organisation.

Using the IBM HR Analytics Employee Attrition dataset, the project combines exploratory data analysis, statistical analysis, feature engineering and machine learning to investigate factors associated with employee attrition and develop predictive models.

The project was completed by Data Zest as part of the Data Science Capstone Project for Cohort 7.

---

## Business Problem

Employee attrition can have significant operational and financial consequences for organisations.

The objective of this project is to answer three key questions:

1. What factors are associated with employee attrition?
2. Can machine learning be used to identify employees who may be at risk of leaving?
3. What practical actions can organisations take to improve employee retention?

---

## Project Objectives

The project aims to:

- Understand and clean the employee dataset.
- Explore demographic, job-related and workplace factors associated with attrition.
- Identify statistically significant relationships with employee attrition.
- Engineer and preprocess features for machine learning.
- Develop and compare multiple classification models.
- Evaluate model performance on previously unseen data.
- Identify important factors contributing to model predictions.
- Translate analytical findings into practical employee-retention recommendations.

---

## Dataset

The project uses the IBM HR Analytics Employee Attrition dataset available through Kaggle.

The dataset contains employee demographic, job, compensation, satisfaction and workplace information.

The target variable is:

- `Attrition = Yes` — Employee left the organisation.
- `Attrition = No` — Employee remained with the organisation.
