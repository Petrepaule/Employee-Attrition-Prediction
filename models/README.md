# Models

This folder contains the machine learning artefacts developed during the Employee Attrition Prediction project.

## Contents

- `phase3_preprocessor.pkl` – Fitted preprocessing pipeline used to transform the data.
- `svm_model.pkl` – Final Support Vector Machine classification model.
- `logistic_regression_model.pkl` – Trained Logistic Regression model.
- `gradient_boosting_model.pkl` – Trained Gradient Boosting model.

These artefacts allow the trained models to be reused for prediction without retraining.
