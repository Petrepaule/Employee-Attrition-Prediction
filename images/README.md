# Images

This folder contains selected visualisations generated during the Employee Attrition Prediction project.

## Included Visualisations

### 1. Attrition Distribution
Shows the distribution of employees who stayed versus those who left the organisation, highlighting the class imbalance in the dataset.

### 2. Pairplot
Illustrates the relationships between selected high-impact numerical variables and employee attrition, helping identify patterns and potential separability between classes.

### 3. ROC Curve
Displays the Receiver Operating Characteristic (ROC) curves for the evaluated classification models, illustrating their ability to distinguish between employees who stayed and those who left.

### 4. Model Comparison
Compares the performance of the evaluated machine learning models using key metrics such as Accuracy, Precision, Recall, F1-score, and ROC-AUC.

These visualisations support the exploratory analysis and model evaluation discussed throughout the project.
